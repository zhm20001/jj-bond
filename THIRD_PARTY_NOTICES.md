# Third-party dependencies

jj-bond is licensed under Apache-2.0. Dependencies retain their own licenses.

[LICENSES/manifest.json](LICENSES/manifest.json) identifies exact versions,
license expressions, original notice files, checksums and source archive URLs.
[LICENSES/texts/](LICENSES/texts/) contains the corresponding texts. The entire
LICENSES directory is bundled with the desktop app. Coverage includes all
locked Cargo dependencies and npm production dependencies; development-only
npm packages are inventoried separately in [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md).

For MPL-2.0 components, the manifest links the exact unmodified upstream source
archive. No dependency source was modified. Other licenses and package-specific
notices remain applicable; the project license does not replace them.

The current application icon is the hand-authored assets/icon01.svg, also used
in the toolbar. See [assets/README.md](assets/README.md). No external fonts are
bundled; the interface uses installed system fonts.
